# DrivePlay

> A Better Way to Watch.

DrivePlay is a modern, smooth, browser-based video player designed to provide a better viewing experience for authorized video content, starting with Google Drive links.

## Vision

DrivePlay aims to combine the simplicity of cloud-hosted video with the control and polish of a dedicated media player.

Planned capabilities include:

- Smooth, responsive playback
- Playback speed controls
- Press-and-hold temporary 2× speed
- Subtitles and subtitle styling
- Audio track selection
- Fullscreen and Picture-in-Picture
- Resume playback
- Mobile-first touch controls
- Performance-focused player architecture

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Zustand
- Native HTML5 Media APIs
- WebVTT
- Cloudflare Workers for backend/media-resolution functionality where required

## Development

This repository is being built incrementally. The first milestone is validating the Google Drive media pipeline and reliable browser playback before adding the full premium player experience.
